===============================================================================
1. CORE ARCHITECTURE & SYSTEM OVERVIEW
===============================================================================
- Base URL: https://api.pexels.com/v1/
- Protocol: HTTPS
- Authentication Method: Custom HTTP Header (Authorization)
- HTTP Header Format: 
  Authorization: [YOUR_API_KEY]
- Content-Type: application/json
- Rate Limiting: 25,000 requests per month.
- Rate Limit Headers (Returned in every API response):
  * X-Ratelimit-Limit: The maximum number of requests allowed per month/period.
  * X-Ratelimit-Remaining: The number of requests remaining in the current window.
  * X-Ratelimit-Reset: The timestamp when the rate limit resets.

6. EXPLICIT AI AGENT IMPLEMENTATION RULES & HEURISTICS
===============================================================================
1. Header Invalidation Fault Protection:
   Do NOT pass the API key in the URL string. The Pexels API will completely reject the request with a 401 Unauthorized error. You MUST inject the key strictly into the HTTP Request Headers using the exact key: `Authorization`.

2. Video Quality Parsing Selection:
   The `video_files` field is an array of objects representing different qualities (e.g., "hd", "sd"). AI Agents parsing this response MUST iterate through `video_files` and sort or select the desired file asset by combining the `quality`, `width`, and `file_type` fields.

3. Pagination Convergence:
   Monitor `total_results` inside the search/popular response. Program loops to increment the `page` index parameter. Halt execution safely when `(page * per_page) >= total_results` or when `video` list array is empty.

4. Graceful Error & Throttling Mitigation:
   If an HTTP 429 status is returned, the client wrapper must automatically read the `X-Ratelimit-Reset` header or apply exponential backoff. Do not continuous-retry without window exhaustion check.
