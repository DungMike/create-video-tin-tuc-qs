#         venv/Scripts/python -m src.tools.sync_keyword_files

#     trùng ảnh. Muốn cảnh đa dạng thì ưu tiên từ CHƯA DÙNG.
#   - Chọn nguồn Pexels: key Pixabay chưa có full API access nên ảnh Pixabay quá nhỏ
#     (<= 1280px) và bị loại hết.
#   - Thêm từ khóa: viết thêm dòng vào CHƯA DÙNG (có thể tạo nhóm "## Tên nhóm") rồi
#     chạy lệnh trên; từ đã tìm hoặc lặp lại tự bị loại.
