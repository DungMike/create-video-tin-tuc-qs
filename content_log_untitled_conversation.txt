Vấn đề hiện tại
Overlay hiện chỉ thêm noise texture lên trên video gốc, nhưng không thay đổi color grading của video nền. Video gốc giữ nguyên màu sắc hiện đại (xanh tươi, sắc nét) → không giống TV cũ 1990s.

3 Options đề xuất

Option A: Color Grade tích hợp vào filter chain overlay (⭐ Khuyên dùng)
Ý tưởng: Thêm color grading filters trước khi overlay noise, trong cùng lệnh FFmpeg.
[0:v] → eq(saturation,contrast) → colorbalance → curves → [colored_base][colored_base] → [tvnoise0] overlay → [tvnoise1] overlay → [waveform] overlay → format=yuv420p
Ưu điểm:

✅ 1 pass duy nhất - không tăng thời gian render
✅ Không file trung gian - không tốn disk
✅ Dễ tùy chỉnh - thêm/bớt filter trong chain
✅ Tương thích NVENC - vẫn dùng GPU encode

Nhược điểm:

⚠️ Filter chain dài hơn → CPU decode load tăng ~5-10%
⚠️ Cần sửa _apply_story_overlays() trong pipeline

Hiệu suất: ~5% tăng thời gian so với hiện tại

Option B: Semi-transparent color overlay layer
Ý tưởng: Tạo một lớp màu bán trong suốt (sepia/amber) overlay lên video gốc cùng với noise.
[0:v] → [base]color=c=#8B7355:s=1920x1080,format=rgba,colorchannelmixer=aa=0.12 → [tint_layer][base][tint_layer] overlay=0:0 → [tinted][tinted] → [tvnoise0] overlay → ...
Ưu điểm:

✅ Có thể tạo thành overlay file riêng (dùng lại)
✅ Opacity dễ điều chỉnh

Nhược điểm:

❌ Chỉ thêm tint, không giảm saturation hay contrast
❌ Không authentic - TV cũ không chỉ đơn thuần là tint màu
❌ Cần thêm 1 input stream → phức tạp hơn


Option C: Kết hợp color grade + noise vào 1 lớp preprocess
Ý tưởng: Sửa lại preprocess bước alpha MOV để bake color tint vào noise overlay.
Preprocess: source → lumakey → alpha MOV (có sẵn color tint overlay)Pipeline: [0:v] eq+colorbalance → [noise_with_tint] overlay → done
Ưu điểm:

✅ Noise + color tint = 1 lớp duy nhất
✅ Pipeline overlay đơn giản

Nhược điểm:

❌ Không thể tách rời color grade và noise
❌ Mỗi thay đổi color → phải regenerate alpha MOV
❌ Vẫn cần eq/colorbalance cho video base (không thể chỉ overlay)
