# PIXABAY API SPECIFICATION & INTEGRATION GUIDE
# Target Audience: AI Code Generation Agents & Developers
# Output Format: Structured Text Reference (.txt)

===============================================================================
1. CORE ARCHITECTURE & SYSTEM OVERVIEW
===============================================================================
- Base URL (Images/Illustrations/Vectors): https://pixabay.com/api/
- Base URL (Videos):                     https://pixabay.com/api/videos/
- Protocol: HTTPS
- HTTP Method: GET (All requests must be made via GET)
- Content-Type: application/json (Responses are strictly returned as JSON objects)
- Rate Limiting: 5,000 requests per hour.
- Rate Limit Headers (Returned in every API response):
  * X-RateLimit-Limit: The maximum number of requests allowed per hour.
  * X-RateLimit-Remaining: The number of requests remaining in the current hour window.
  * X-RateLimit-Reset: The remaining time in seconds until the rate limit resets.

Authentication Requirement:
- Authentication is handled exclusively via a query parameter named `key`.
- Custom headers for authentication are NOT supported.
- Pass the API key directly into the URL: `?key=YOUR_API_KEY_HERE`

4. EXPLICIT AI AGENT IMPLEMENTATION RULES & HEURISTICS
===============================================================================
1. URL Encoding Rule:
   Every dynamic value passed to the `q` parameter MUST be explicitly URL-encoded before sending the request. Spaces should be mapped to `+` or `%20`.

2. Authentication Injection Rule:
   Do NOT attempt to inject bearer tokens or API keys into headers like `Authorization` or `X-API-Key`. The system will throw a 401/403. Always inject via URL query params (`?key=...`).

3. Pagination Heuristic:
   To ingest complete datasets, monitor `totalHits`. Iterate through pages using the `page` parameter while setting `per_page=200` (max efficiency value) until `page * per_page >= totalHits`.

4. Caching Compliance (Terms of Service):
   Your application MUST cache API data and assets (images/videos) for at least 24 hours. Set native downstream caching headers to `Cache-Control: max-age=86400`.

5. User Interface Attribution Rule:
   If your AI code displays these assets on an end-user interface, you MUST provide a direct link back to Pixabay and credit the source as per the `pageURL` field.

===============================================================================
5. CORE ERROR CODES & HANDLING STRATEGY
===============================================================================
- HTTP 400: Bad Request (Invalid parameters or out-of-range configurations).
- HTTP 429: Too Many Requests (Rate limit hit. Code must catch this status, parse the `X-RateLimit-Reset` header, and halt execution until the specified epoch/seconds expire).
- HTTP 401 / 403: Invalid or missing API key parameter.
